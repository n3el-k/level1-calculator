# Calculator (Level 1 practice project)

A command-line calculator that reads an expression and prints the result.

```bash
python main.py
```

Run the tests:

```bash
python -m pytest
```

## Tickets

1. Make `add()` and `subtract()` return the right answer. ✅
2. Handle dividing by zero. ✅
3. Evaluate a whole expression like `2 + 3 * 4`.
